# Documentation images

`localsr-desktop.png` is an unedited capture of LocalSR v0.1.1-beta on macOS
(MacBook Pro with an M1 Pro, 16 GB), taken on 15 September 2026. It shows the
comparison view after upscaling a 384 × 384 photograph 4× with the Quick preset
(SPAN ×4 NomosUni).

The photograph is Apollo 17 image **AS17-148-22727**, courtesy of the Earth
Science and Remote Sensing Unit, NASA Johnson Space Center
([source](https://svs.gsfc.nasa.gov/30613) ·
[media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/)).
The input was reduced to 384 pixels for the capture and LocalSR produced the
enhanced side. NASA does not endorse LocalSR.
