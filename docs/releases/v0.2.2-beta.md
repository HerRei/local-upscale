# LocalSR v0.2.2-beta

Videos are compared the way photos are, with playback controls below the
picture.

## What changed

**One stage for photos and videos.** A finished video now sits on the same
canvas as a photo. The divider stops at the edges of the frame instead of
running across the empty canvas, and the zoom controls, now with 1:1, appear
while the pointer is over the video. Scrolling, pinching and View › Fit to
Window and Actual Pixels work for videos too. Original · Split · Enhanced and
holding **M** work as before.

**Playback below the frame.** Play and pause, the time, a thin scrubber and the
speed (0.5×, 1×, 1.5× and 2×) sit in one bar under the video, in the same style
as the zoom controls. **Space** plays and pauses. Both versions still play in
sync.

**Rotated videos with PyAV 19.** Videos whose track carries a rotation (a
display matrix, common on phones) stopped the engine when it ran with PyAV 19,
which changed how frame side data is read. The engine now reads it in a way
that works from PyAV 12 to 19. The published packages ship PyAV 18.1 and were
not affected; installs from source that picked up PyAV 19 were.

## Download

[Download page](https://herrei.github.io/localsr/download/). The Mac mini
serves the files through the Infomaniak VPS; the attached GitHub files are
mirrors.

- `LocalSR-v0.2.2-beta-macOS-arm64.dmg` — Apple Silicon, macOS 14 or later.
  Developer ID signed and notarized by Apple. Installed macOS betas receive
  this version through the app's update check; the update includes the
  inference engine.
- `LocalSR-v0.2.2-beta-Windows-CPU-x86_64.exe` — Windows 10 or 11, x86-64.
  Unsigned, so SmartScreen asks first. DirectML and NVIDIA CUDA editions are
  attached as well and remain untested on those GPUs.
- `LocalSR-v0.2.2-beta-Linux-CPU-x86_64.AppImage` — x86-64, glibc 2.39 or
  later. AMD ROCm and NVIDIA CUDA editions come in parts.
- `*-source-and-notices.tar.gz` — source, build instructions and third-party
  notices for each build.

File checksums are in `SHA256SUMS` and the `.sha256` files.

## Validation

The video comparison was checked in the interface tests (186 pass) and with the
real preview in a browser on a 4× result of a 320×240 MJPEG clip from 2007:
the video fits the canvas, the divider stays on the frame while dragging, 1:1
shows 228 %, and play, pause, scrubbing, speed and Space work. The same clip
was upscaled with Best in a development build of the desktop app on a 16 GB
M1 Pro.
The rotation fix passes the video timing and HDR tests with PyAV 18.1 and
19.0.2 and was also run against PyAV 12.3. The packaged Mac app, its engine and
every Windows and Linux package went through the same automated build checks
as v0.2.1-beta.

## Known limitations

Editing, SeedVR2, HDR preservation, de-flicker and video face processing remain
experimental. See [KNOWN_LIMITATIONS.md](https://github.com/HerRei/local-upscale/blob/main/KNOWN_LIMITATIONS.md)
for the current list.

Report problems on [GitHub Issues](https://github.com/HerRei/local-upscale/issues)
with your app version and steps to reproduce.
