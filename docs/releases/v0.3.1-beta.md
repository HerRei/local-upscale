# LocalSR v0.3.1-beta

Release candidate, not published yet (prepared 2026-11-07).

## What changed

### Changed

- The Linux CPU and NVIDIA CUDA AppImages are now built on Ubuntu 22.04, so they
  run on Ubuntu 22.04 and on other distributions with glibc 2.35 or newer;
  v0.3.0-beta needed glibc 2.39 (Ubuntu 24.04). The AMD ROCm AppImage still needs
  glibc 2.39. Before release, every AppImage is checked the way the AppImage
  catalog checks it: no file in it may need a newer glibc than its edition
  allows, and it must open its window without a network connection.
- On a Mac, Homebrew installs LocalSR: `brew install --cask herrei/tap/localsr`.
- Dependency updates, among them Tauri 2.12.
