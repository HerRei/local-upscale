# LocalSR v0.0.9-alpha

This is a **private security-hardening alpha**, not a public beta. It closes several concrete code
and release-pipeline risks without deciding platform support, signing credentials, model licensing,
repository visibility, or public-feedback policy.

## Security changes

- Curated pickle checkpoints are SHA-256 checked immediately before deserialization. Unverified
  custom `.pth`, `.pt`, and `.ckpt` files are blocked by default; `.safetensors` remains the normal
  custom-model path. The explicit `LOCALSR_ALLOW_UNVERIFIED_CHECKPOINTS=1` escape hatch is trusted
  code, not a sandbox.
- SeedVR2's bundled positive/negative text embeddings are validated Safetensors rather than pickle
  `.pt` files, so normal Labs video execution no longer deserializes those bundled objects. Its
  vendored fallback downloader also rejects non-HTTPS URLs and redirects.
- Installed image and SeedVR2 model files are no longer accepted by size alone. Cached SHA-256
  checks detect corrupt or same-size replaced files and force a clean download.
- Release artifact uploads use timestamped, nonce-bound HMAC requests. The reusable secret is no
  longer transmitted over LAN HTTP, signed metadata cannot be altered, and replays are rejected.
- Linux release jobs prune only validated, regenerable inputs from their active scratch directory
  before archiving, keeping the runner's protected SSD reserve intact even for the ROCm bundle.
- GitHub Actions checkout is pinned to an immutable commit, checkout credentials are not persisted,
  only the final release-publishing job receives `contents: write`, and future Apple credentials are
  scoped to the dedicated signing step.
- The Windows portable installer now downloads and verifies the matching `.sha256` before changing
  the existing installation. The Python installer no longer invokes a command shell for GPU probes.
- Maintained Linux and Windows CPU/CUDA/XPU/ROCm builds move to PyTorch 2.13.0. Modern platforms use
  Diffusers 0.38.x, which includes the custom-pipeline security fixes.

## Still not public-beta ready

- Developer ID signing/notarization/stapling and Windows Authenticode credentials are absent.
- macOS Intel/Apple-Silicon cross-builds remain constrained to PyTorch 2.2.2. Windows DirectML is
  constrained by Microsoft's preview package to PyTorch 2.4.1. Default checkpoint blocking reduces
  exposure but does not turn either legacy runtime into a supported public-beta dependency.
- Physical platform/media/resource-pressure acceptance remains incomplete.
- The noncommercial face-model policy and the ambiguous Best/anime upstream license remain open.
- The private repository, public downloads/feedback choice, unavailable branch protection, disabled
  code/secret scanning, and persistent-runner isolation remain owner decisions.
- Video and SeedVR2 remain Labs / Experimental.

## Download and verify

Choose one backend archive and verify its `.sha256`, `.metadata.json`, and
`.architecture.txt` sidecars (or follow `release-index.json` for split assets). Read
`beta-readiness.json`; `beta_ready` is intentionally `false`.
