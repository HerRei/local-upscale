# LocalSR v0.0.12-alpha

This testing-only alpha introduces local video processing, a fully integrated benchmark studio, and packages CPU, CUDA, ROCm, Intel XPU, DirectML, and MPS for their corresponding target platforms.

## Download

Choose the installer matching your system and GPU backend:

- `LocalSR-v0.0.12-alpha-macOS-arm64.dmg` — Apple Silicon macOS (MPS)
- `LocalSR-v0.0.12-alpha-Windows-CPU-x86_64.exe` — Windows 10/11 (CPU)
- `LocalSR-v0.0.12-alpha-Windows-DirectML-x86_64.exe` — Windows 10/11 (DirectML)
- `LocalSR-v0.0.12-alpha-Windows-CUDA-x86_64.exe` — Windows 10/11 (CUDA)
- `LocalSR-v0.0.12-alpha-Linux-CPU-x86_64.AppImage` — Linux x86-64 (CPU)
- `LocalSR-v0.0.12-alpha-Linux-CUDA-x86_64.AppImage` — Linux x86-64 (CUDA)
- `LocalSR-v0.0.12-alpha-Linux-Intel-x86_64.AppImage` — Linux x86-64 (Intel-XPU)
- `LocalSR-v0.0.12-alpha-Linux-ROCm-x86_64.AppImage` — Linux x86-64 (AMD-ROCm)

Windows CUDA requires the installer **and all matching `.engine.tar.gz.part-*` files** in the
same folder. Run the installer to verify and install the engine automatically. No Python setup is
required. Large Linux AppImages use `.part-*` files and a matching `.restore.sh` helper: download the
complete set, run `bash <matching-file>.restore.sh`, and launch the reconstructed AppImage.

Verify every downloaded file against `SHA256SUMS`. `release-index.json` records the exact source commit,
selected workflow attempt, architecture, worker smoke, model, and signing evidence.

## Important trust warning

This is an explicitly testing-only release. The macOS app is ad-hoc sealed, is not Developer ID
signed or notarized, and was only statically cross-build verified on the Intel Mac mini. The
Windows installer is not Authenticode signed. Gatekeeper or SmartScreen may warn or reject these
downloads. Production signing, notarization, timestamping, native Apple-Silicon execution, and
physical target testing remain mandatory beta gates.

## Highlights

- **Hardware Acceleration:** Restored matrix packaging for CUDA, DirectML, and ROCm, allowing native hardware acceleration on Windows and Linux without manual PyTorch installations.
- **Video Pipeline:** Standard SDR frame processing has corrected timing, orientation, trimming, and cancellation. SeedVR2, de-flicker, and motion-sensitive face processing keep their individual experimental labels.
- **Benchmark Studio:** New visual benchmark studio UI (`BenchmarkStudio.svelte`) for reproducible performance diagnostics and comparison.
- **Documentation:** Added detailed `video-support.md` and `VIDEO_PIPELINE_HANDOFF.md` documentation.
- Hardens the CI tools and cross-platform release builder definitions.

## Known limitations

- Installed-platform and physical GPU acceptance remains pending. Temporal models, de-flicker, and
  video face processing remain individually experimental; standard video is tracked separately.
- Optional model weights keep their upstream licenses. The HAT-S Face checkpoint has unresolved
  independent weight/training-data rights and is accepted only as a hash-matching user-supplied
  file. Models with ambiguous terms are not presented as commercially licensed.

## Reliability and maintenance

Image jobs now release their preview encoder and temporary outputs before reporting completion,
cancellation, or failure. Corrupt inputs and output-write failures are tested with a succeeding
queued job. The desktop queue, comparison preview, and advanced settings have separate components,
and native listeners registered after window shutdown are released immediately.

Development checks now include gradual Python type checking alongside the Python, Svelte, Rust,
and packaging checks through `./local-ci.sh`. All backend variants remain in the release matrix.
