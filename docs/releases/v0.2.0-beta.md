# LocalSR v0.2.0-beta

A calmer, simpler window, redesigned for people who open LocalSR for the first
time.

## Why

The first minutes with LocalSR asked too much. Two or three places offered to
download a model, presets were named after model codenames, a top bar repeated
the app name next to buttons that already lived in the menu bar, and blue,
green and amber text competed with the photo you were trying to judge. This
release keeps what LocalSR does and changes how it asks you to do it.

## What changed

**One way to start.** Add a photo, pick Quick or Best, press the button at the
bottom right. If the model is not on your computer yet, the button says so
("Download 4 MB, then upscale") and does both; while it downloads, the same
button cancels. Per-model download buttons, the first-run download notice and
the license box with its own download button are gone. A model's license is a
one-line credit with links to its source and terms.

**Plain choices.** Quick and Best are described by what you get, and each card
names the download it still needs. Upscale, Restore and Edit form one switch
with a single caption, and Upscale handles videos too, so the separate Upscale
Video task is gone. Models that are ready carry no label. A line beside the
button says what the next job will make, for example
`2268 × 4032 → 9072 × 16128 · 4× · Apple GPU (Metal)`.

**No top bar.** On wide windows the pane headings form the top of the window,
with the window buttons beside Media. The model library opens from
**View › Models…** (⇧⌘M) or the **Change…** link under Model, the benchmark from
**View › Performance and Diagnostics…**, and updates from **LocalSR › Check for
Updates…** (Help on Windows and Linux). Narrow windows keep a slim bar to switch
between panes.

**A quieter look.** The app ships IBM Plex Sans, so Mac, Windows and Linux show
the same typeface. Corners are square, panels are neutral grey so colours are
judged against a neutral surround, and colour appears in one place: the button
that starts work and its progress, in the terracotta of the logo. Until there
is something to start, the window has no colour at all.

**Comparisons read left to right.** The original is on the left of the divider
and the result on the right, for images and video, matching the labels.

## Fixed

- New installations start on the GPU (Apple silicon, CUDA or ROCm). A fresh
  install used to default to the CPU, so a first upscale on a Mac ran several
  times slower than necessary until Hardware was changed under Advanced.
- Choosing Best no longer shows two download buttons for one file, with two
  different sizes.
- The window fits small screens. On a 1366 × 768 laptop or a 1280 × 800 display
  the bottom bar with the start button used to sit under the taskbar.
- Edit no longer offers to download a model on a computer where the edit cannot
  run.

## Download

[Download page](https://herrei.github.io/localsr/download/). The Mac mini
serves the files through the Infomaniak VPS; the attached GitHub files are
mirrors.

- `LocalSR-v0.2.0-beta-macOS-arm64.dmg` — Apple Silicon, macOS 14 or later.
  Developer ID signed and notarized by Apple. Installed macOS betas receive
  this version through the app's update check; the update includes the
  inference engine.
- `LocalSR-v0.2.0-beta-Windows-CPU-x86_64.exe` — Windows 10 or 11, x86-64.
  Unsigned, so SmartScreen asks first. DirectML and NVIDIA CUDA editions are
  attached as well and remain untested on those GPUs.
- `LocalSR-v0.2.0-beta-Linux-CPU-x86_64.AppImage` — x86-64, glibc 2.39 or
  later. AMD ROCm and NVIDIA CUDA editions come in parts.
- `*-source-and-notices.tar.gz` — source, build instructions and third-party
  notices for each build.

File checksums are in `SHA256SUMS` and the `.sha256` files.

## Validation

On a 16 GB M1 Pro with the packaged app: first launch in an empty profile,
Quick and Best downloads (including cancelling and resuming one), upscales of a
JPEG, a 2268 × 4032 HEIC (to 9072 × 16128) and a short H.264 clip with audio, a
JPEG-artifact fix before upscaling, Restore, a three-image batch, a FLUX.2
klein edit, the model library, the benchmark, Check for Updates and a narrow
window. The packaged worker passed the real-model acceptance run on the GPU.
The Windows CPU installer was installed and used in a Windows 11 virtual
machine. 767 Python, 179 interface and 84 host tests pass.

## Known limitations

Editing, SeedVR2, HDR preservation, de-flicker and video face processing remain
experimental. See [KNOWN_LIMITATIONS.md](https://github.com/HerRei/local-upscale/blob/main/KNOWN_LIMITATIONS.md)
for the current list.

Report problems on [GitHub Issues](https://github.com/HerRei/local-upscale/issues)
with your app version and steps to reproduce.
