# LocalSR v0.6.2-beta

## Which file do I need?

Download one file for your computer; it is all you need. The Mac version includes everything. On Windows and Linux, LocalSR checks your graphics card when it first starts and offers the faster engine for it (NVIDIA CUDA, DirectML for AMD and Intel graphics on Windows, AMD ROCm on Linux), then downloads and installs that engine itself.

| Computer | Download |
|---|---|
| Mac (M1 or newer) | `LocalSR-v0.6.2-beta-macOS-arm64.dmg` |
| Windows | `LocalSR-v0.6.2-beta-Windows-CPU-x86_64.exe` |
| Linux | `LocalSR-v0.6.2-beta-Linux-CPU-x86_64.AppImage`, or `LocalSR-v0.6.2-beta-Linux-CPU-amd64.deb` on Ubuntu and Debian |

## Offline and advanced downloads

Only for a computer without internet access, or to install the GPU edition in one go. Everyone else can skip this.

| Computer | Download |
|---|---|
| Windows, AMD or Intel graphics | `LocalSR-v0.6.2-beta-Windows-DirectML-x86_64.exe` |
| Windows, NVIDIA | `LocalSR-v0.6.2-beta-Windows-CUDA-x86_64.exe` and all `LocalSR-v0.6.2-beta-Windows-CUDA-x86_64.engine.tar.gz.part-*` files in the same folder |
| Linux, AMD | all `LocalSR-v0.6.2-beta-Linux-ROCm-x86_64.AppImage.part-*` files, joined |
| Linux, NVIDIA | all `LocalSR-v0.6.2-beta-Linux-CUDA-x86_64.AppImage.part-*` files, joined |

To import an engine offline, download the `*.engine-payload.json` manifest, its `.engine.tar.gz.part-*` files and their `.sig` signature files into one folder, then open **Advanced -> Engine -> Change… -> Import engine from file…** and choose the `*.engine-payload.json` file.

### What are all the other files?

- `*.engine-payload.json`, `*.engine-update.json` and `*.engine.tar.gz.part-*`: the GPU engines that the app downloads by itself.
- `*.app.tar.gz` and `*.sig`: update files and their signatures, which the app checks before it installs an update.
- `*.sha256` and `SHA256SUMS`: checksums to check a download by hand.
- `*source-and-notices.tar.gz`: the source code and licence notices for each package.

## What changed

A small speed and responsiveness update. Nothing changes in the results.

- **Editing is much faster on NVIDIA and other GPUs (#194).** LocalSR started the
  editing engine with only 2 CPU threads, a setting meant for Macs with little memory.
  It now uses all of them, which a user measured at about twice as fast on a CUDA PC.
  Where the text encoder and the decoder run (GPU or CPU) will be chosen by the
  graphics memory in 0.7.0.
- **Edits start sooner.** Every edit checked the whole 8 to 21 GB editing model again
  before it began. LocalSR now checks it once per session and again only when a file
  has changed.
- **Large photos finish faster.** The result was written to disk after every tile;
  it is now written once at the end.
- **A calmer app while downloading and adding files.** A model download refreshed the
  whole app state about 12 times a second, and every engine event copied all photo
  previews. Downloads now only update their progress bar, and events copy only what
  they change, so adding a large folder no longer freezes the window.
- **Less work while idle.** The animation on the empty start screen stops while the
  window is hidden, an invisible animation no longer runs, and progress bars no longer
  animate their width on every update.
- **Faster start when offline.** The update check at launch no longer delays drag and
  drop or "Open with LocalSR".
- **Faster engine restarts** after you stop a job or switch the engine (no 1 s pause).
