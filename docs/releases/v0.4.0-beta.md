# LocalSR v0.4.0-beta

Release candidate, not published yet (prepared 2026-11-10).

## What changed

This is the first public release since v0.3.0-beta. It adds support for built-in
graphics and Intel NPUs, updates inside the app on Windows and Linux, comparing saved
results, HEIC and MOV output on the Mac, and a long pass over reliability and the
interface. If you run the Windows or Linux build of v0.3.0-beta, install this version
once from the download page; it uses the same settings, queue and models folder, and
later versions update in the app.

### Since v0.3.0-beta

- **Graphics and NPUs.** On Windows, DirectML can use built-in graphics (Intel, AMD
  Radeon), and Intel graphics also appear as OpenVINO devices on Windows and Linux. A
  GPU is used only after LocalSR has compared its result with the CPU's, and a driver
  that crashes during that test is left alone. Intel NPUs run SPAN, Real-ESRGAN, FBCNN and
  NAFNet on Windows and Linux.
- **Updates on every system.** Windows and Linux builds now update themselves, with
  signed update statements that also cover package sizes and parts. The update switches
  in the LocalSR menu stop the check at launch or the anonymous count.
- **Fixes before upscaling.** Choose the model for each fix, run up to three in order
  (noise, JPEG, blur), and see in the Model plan how many models fit the task. A fix the
  model cannot process is skipped with a note instead of ending the job.
- **Compare.** Pick up to four results in Outputs and compare them with a slider or
  linked boxes at full resolution. "Try others" queues two to four installed models on
  one image.
- **Output formats.** On the Mac, HEIC images and MOV video with HEVC or Apple ProRes.
- **Video.** Optional frame interpolation (2x, 4x, 60 or 120 fps), a Labs feature that
  is off by default.
- **Photos.** Queued photos with the same plain recipe (SPAN, Real-ESRGAN or FBCNN, no
  fixes or Faces) run as a batch on Apple Silicon, about 1.9 to 2.8 times faster than one
  at a time on an M1 Pro. Grey scans keep their grey, and 16-bit grey and CMYK profiles
  are read correctly.
- **Models.** Two DAT2 models join the library, the Hardware menu groups each graphics
  card's routes, and the model library shows each author, source and licence.
- **Packaging.** Linux AppImages need glibc 2.35, so they run on Ubuntu 22.04, and the
  ROCm and CUDA ones are about a third smaller. On the Mac, Homebrew installs LocalSR
  and closing the window no longer quits the app.

### Reliability

- A result is never written over an existing file, including names that differ only in
  case or Unicode form.
- Before a job starts, LocalSR checks that its files fit on the output's disk and keeps
  8 GB free on the system volume. A full disk stops the queue once with a plain message.
- The remaining-time estimate is rewritten. It starts only once a steady speed is
  measured, counts down by itself and changes in steps that do not flicker.
- Core ML preparation has a 120 second limit per job. A program that does not finish is
  remembered and tried again after a week or after an app or macOS update. Intel NPU
  models are compiled in a separate process.
- Engine processes are stopped as a whole group, and a damaged queue database is set
  aside so the app starts.
- FFmpeg and the editing runtime are chosen only through the app's own file dialogs.
- Editing on a Mac no longer stops for 2 GiB of swap.

### Interface

- Two start buttons: "Only this one" and "Upscale all N".
- Inputs and Outputs tabs with counts; Compare opens only from "Compare these N".
- A clearer running row, "Saving…" and "Stopping…" states, and removing inputs while a
  queue runs.
- Click a result to show it, "Use as input" to use it as a new input, Clear on Outputs.
- Help "?" tips on the Advanced controls and a hardware line on every library row.
- The Illustration choice picks illustration models: Real-ESRGAN Anime 6B for Quick
  and RealPLKSR HFA2k for Best.

## Known limitations

- The Windows and Linux builds of this version were tested by automated checks: the
  installed app starts and its engine answers. The hands-on testing was on an Apple
  Silicon Mac.
- The Illustration choice was changed to the illustration models without a visual
  comparison against the previous behaviour.
- The CUDA editions have never run on an NVIDIA GPU, and DirectML's NAFNet denoising
  misses its accuracy tolerance. Intel NPUs on Windows have not been tried on real
  hardware, and AMD NPUs are not supported.
- Frame interpolation is a Labs feature; its 1080p and 4K speed and memory use on the Mac
  are not validated. De-flicker, editing, SeedVR2 and HDR preservation also remain
  experimental.
- Windows installers are not code-signed, so SmartScreen asks first.

See [KNOWN_LIMITATIONS.md](https://github.com/HerRei/local-upscale/blob/main/KNOWN_LIMITATIONS.md)
for the current list. Report problems on
[GitHub Issues](https://github.com/HerRei/local-upscale/issues) with your app version and
steps to reproduce.
