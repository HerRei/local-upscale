## Changes

- Common legacy AVI/DivX, MPEG/VOB, camcorder, WMV/ASF, FLV and mobile-video
  imports; normalize tagged interlacing and display aspect ratio, convert legacy
  soundtracks to AAC for MP4, and prepare compatible comparison copies with
  progress and cancellation. [Source tests and limits](../beta-legacy-video-2026-09-13.md).

- Retire Slint and its installer. The Python launcher opens the separately installed
  Tauri app; the engine, automation CLI and optional Qt Widgets client remain.

- Live processing squares follow the actual model tile geometry, including
  partial edges, switching to an unseen running image and denoise/upscale stages.
- Completed-image comparison stays responsive during another queued job;
  video comparisons retain the selected result when switching between items.
- Folder jobs save together in `LocalSR Results`. Current-job, next-job and
  whole-queue estimates distinguish measured timing from unmeasured work.
- CPU and GPU benchmarks have separate scores and actual rendering tiles. The
  v2.1 scene avoids SPAN’s unstable full-range noise input; slow devices collect
  at least three measurements before a score can pass the consistency gate.
  Earlier benchmark revisions are not comparable.
- The prepared Windows ONNX path uses maintained Torch 2.13 for CPU/loading and
  verified DirectML execution for compatible models. NAFNet SIDD still fails the
  strict photo-equivalence gate; its runtime policy is awaiting a decision.
- Cancellation can recover a stalled worker and process another job. Unstable
  NAFNet scan output is detected before an export is committed.
- Both HAT face companions remain available through verified user import.
- NomosWebPhoto/HFA2k downloads show the author's CC BY 4.0 terms, credit and
  source links. Checkpoint files and integrity pins are unchanged.
- Windows MSIX uses Store-managed application updates. Direct editions have
  signed update verification and local settings/recipes/queue recovery.
- Updated project/developer guides include a real desktop screenshot, a full
  model guide and current build commands. Local CI checks source formatting
  and selects the appropriate beta or alpha release gates.

## Hardware and limitations

All eight backend targets remain in scope. Recorded main-path workloads use
Apple Silicon/MPS, Linux RX 9060 XT/ROCm and native Windows CPU/Intel UHD 620
DirectML. Other NVIDIA, Linux XPU and DirectML adapters remain Labs pending
matching physical hardware results. See the [coverage matrix](../beta-platform-matrix.md)
for package-specific acceptance; availability does not imply universal compatibility.

The maintained native macOS candidate requires Apple Silicon and macOS 14+.
Windows CPU/DirectML acceptance used Windows 11 Home, 16 GB system memory and
Intel UHD 620 driver 24.20.100.6286. That machine's measured CPU benchmark was
faster than its iGPU benchmark. These are functional single-run results, not
comparative marketing scores or a guarantee for other drivers.

High-resolution video and SeedVR2 need powerful compatible hardware and can
run for hours or days. The complete five-minute, 480×854 → 960×1708 SPAN export
on DDP took about 100 minutes. A nominal 16 GB GPU is not a workload-fit guarantee.

HDR preservation, SeedVR2 3B FP16/FP8, de-flicker and video-face processing retain
individual Labs labels and model/backend limits. SeedVR2 exports SDR and cannot
preserve HDR. HAT's SDR training does not establish HDR restoration quality.

The NAFNet SIDD scan guard rejects two of the eleven reproduced inputs after
bounded retries. No output is written for those failures. AI results still need
inspection, particularly text, faces and scanned documents; keep the originals.

No restoration checkpoints are included in installers. Philip Hofmann's
NomosWebPhoto/HFA2k remain verified publisher downloads under the author-declared
CC BY 4.0 license, with attribution and source/license links. The license permits
sharing and commercial use under its terms; it is not a guarantee of every
third-party/input/output right. See the [model evidence](../beta-model-license-choices.md).
Retained review binaries predate this policy update and need final rebuilding.
