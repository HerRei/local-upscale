# LocalSR v0.3.0-beta

The Mac's Neural Engine does the work, and videos upscale about twice as fast.

## What changed

**The Neural Engine on Apple Silicon.** Quick photo (SPAN), Real-ESRGAN and JPEG
cleanup (FBCNN) now run on the Neural Engine through Core ML, and Best photo
(RealPLKSR) runs on the GPU through Core ML. On a MacBook Pro M1 Pro that made a
tile two to three times as fast as before (SPAN 19 against 38 ms, Real-ESRGAN
anime 95 against 319 ms, FBCNN 61 against 149 ms) while using a fraction of the
energy. HAT, SwinIR, NAFNet and SCUNet stay on the GPU as before.

The first job with a model and tile size converts it into a Core ML program once
(1 to 40 seconds) and keeps it in `~/Library/Caches/LocalSR/coreml`. LocalSR then
runs the first tile both ways and keeps Core ML only if it matches the usual
result and is not slower on your Mac; otherwise the job continues on the GPU.
That check is stored per Mac and macOS version, so newer Macs, whose GPUs can be
faster than their Neural Engine, choose for themselves.

**Hardware: Neural Engine.** The Neural Engine is its own entry under
Advanced › Hardware and the default on Macs that have it. Apple GPU (Metal) keeps
every model on the GPU. Before a job, the status bar names where the selected
model will run, or says that it is unsupported on the Neural Engine.

**Faster video.** Quick runs each frame of a video in one call instead of tiles,
and decoding, upscaling and encoding now overlap. A 15-second 720×1280 iPhone
clip upscaled 4× went from 1.6 to 3.6 frames per second: about two minutes
instead of five.

**Automatic video format.** The new default format hands frames straight to the
Mac's hardware HEVC encoder while the next ones are upscaled, without the
temporary lossless copy. No Mac encodes AV1 in hardware, so MKV exports, HDR
preservation and Windows and Linux use AV1. AV1, VP9, FFV1, H.264 and HEVC can
still be chosen directly; a previous AV1 default becomes Automatic once.

**Play before upscaling.** A video plays in the preview before it has a result,
with the same controls as a finished comparison. While it is being upscaled the
preview shows the live tiles, and the comparison follows when it finishes.

**Zoom beside the playback bar.** The zoom controls next to the video bar no
longer disappear and leave a gap when the pointer leaves the video.

## Download

[Download page](https://herrei.github.io/localsr/download/). The Mac mini
serves the files through the Infomaniak VPS; the attached GitHub files are
mirrors.

- `LocalSR-v0.3.0-beta-macOS-arm64.dmg` — Apple Silicon, macOS 14 or later.
  Developer ID signed and notarized by Apple. Installed macOS betas receive
  this version through the app's update check; the update includes the
  inference engine.
- `LocalSR-v0.3.0-beta-Windows-CPU-x86_64.exe` — Windows 10 or 11, x86-64.
  Unsigned, so SmartScreen asks first. DirectML and NVIDIA CUDA editions are
  attached as well and remain untested on those GPUs.
- `LocalSR-v0.3.0-beta-Linux-CPU-x86_64.AppImage` — x86-64, glibc 2.39 or
  later. AMD ROCm and NVIDIA CUDA editions come in parts.
- `*-source-and-notices.tar.gz` — source, build instructions and third-party
  notices for each build.

File checksums are in `SHA256SUMS` and the `.sha256` files.

## Validation

The Neural Engine path was measured on a 16 GB M1 Pro with the shipped
checkpoints, against PyTorch on the same pixels: SPAN 54 to 57 dB, Real-ESRGAN
71 dB, FBCNN 72 dB, RealPLKSR 69 to 70 dB, with PyTorch 2.13 and 2.14. Whole
images and videos were compared with the GPU path and an untiled reference, the
video speed on a real phone clip, and the packaged worker was frozen and run on
the Neural Engine. The Python (784), interface (191) and host (86) tests pass.
The Windows and Linux packages went through the same automated build and smoke
tests as v0.2.2-beta.

## Known limitations

Only the M1 Pro has been measured; newer Macs decide between the Neural Engine
and the GPU on their first tile. Preparing a model uses up to about 4 GB of
memory once. De-flicker, editing, SeedVR2, HDR preservation and video face
processing remain experimental. See [KNOWN_LIMITATIONS.md](https://github.com/HerRei/local-upscale/blob/main/KNOWN_LIMITATIONS.md)
for the current list.

Report problems on [GitHub Issues](https://github.com/HerRei/local-upscale/issues)
with your app version and steps to reproduce.
