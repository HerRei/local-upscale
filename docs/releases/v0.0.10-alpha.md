# LocalSR v0.0.10-alpha

This is a signed desktop-architecture alpha, not a public beta. It introduces the new
Tauri/Svelte/Rust host without overwriting the former Slint installation or its state.

## What changed

- The visible UI now delegates native authority, persistent queueing, downloads, updates,
  diagnostics, and worker recovery to Rust while PyTorch/Spandrel/video inference remains in an
  isolated Python worker.
- Fit, 1:1 zoom, high-resolution zoom limits, image centering, comparison dragging, completed-tile
  previews, ETA, readable sizing, scrolling, recipes, and native diagnostics have been restored and
  tested in the real macOS GUI.
- Images and videos can share one FIFO queue with their own model/settings. Incompatible task cards
  are disabled and all video surfaces remain Labs / Experimental.
- A multi-gigabyte synchronous model hash was removed from the native UI event loop, eliminating the
  reproducible macOS beachball. Security checks still run before model deserialization in the worker.
- The release gate downloads Quick and Best into a genuinely empty cache, verifies their catalog
  checksums, loads them through Spandrel, and runs real CPU inference before any installer can be
  published. The resulting evidence is embedded in `release-index.json`.

## Simple downloads

Choose exactly one installer:

- `LocalSR-v0.0.10-alpha-macOS-arm64.dmg`
- `LocalSR-v0.0.10-alpha-Windows-x86_64.exe`
- `LocalSR-v0.0.10-alpha-Linux-x86_64.AppImage`

`SHA256SUMS` and `release-index.json` are the only additional verification files. The macOS package
must be Developer ID signed, notarized, stapled, and Gatekeeper accepted. The Windows installer must
have a valid timestamped Authenticode signature. The release pipeline refuses unsigned substitutes
and never overwrites a prior release.

## Still not beta-ready

- Apple and Windows signing credentials and a registered native ARM64 macOS Actions runner must be
  supplied before this candidate can be published.
- Physical real-media acceptance remains open across the supported CPU/MPS packages and proposed
  CUDA, DirectML, ROCm, and Intel XPU engine packs.
- Intel macOS viability, the DirectML runtime path, noncommercial face-model policy, and the
  nonstandard Best/anime upstream license label remain owner/external decisions.
- The private repository still does not provide public downloads or unauthenticated feedback intake.

Do not represent this alpha as a public beta. Review `KNOWN_LIMITATIONS.md`, `SHA256SUMS`, and the
signing/architecture evidence in `release-index.json` before testing.
