# LocalSR v0.1.4-beta

LocalSR can now edit a photo from a written instruction, on your own Mac.

## Download

- `LocalSR-v0.1.4-beta-macOS-arm64.dmg` — Apple Silicon, macOS 14 or later.
  Signed and notarized; uses the Metal (MPS) backend.
- `LocalSR-v0.1.4-beta-macOS-arm64-source-and-notices.tar.gz` — source, build
  instructions and third-party license notices for exactly that build.

Every file's SHA-256 is in `SHA256SUMS` and in the `.sha256` beside it.

Windows and Linux stay on
[v0.1.3-beta](https://github.com/HerRei/local-upscale/releases/tag/v0.1.3-beta)
for now; image editing is not in those builds yet.

Installed macOS betas update themselves: the app checks the feed at launch,
verifies the download's size, SHA-256 and signature, backs up settings, recipes
and the queue, then installs and restarts.

## What's new

- **Edit with a prompt.** Choose *Edit* beside Upscale and Restore, select an
  image and write what should change ("make it winter", "remove the sign").
  The result is a new PNG in your output folder; the original stays untouched.
  Progress, cancel and the before/after comparison work as for every other job.
- **Editing models in the library.** A new *Edit with a prompt* group lists
  Qwen Image Edit 2511 in six sizes (24 GB of memory and up) and FLUX.2 klein
  4B in two sizes, the choice for 16 GB Macs. All are Apache-2.0, downloaded
  only when you choose them (5 to 26 GB), pinned to an exact upstream revision
  and checked with SHA-256 before every use. Each one says what it needs and
  whether it fits this Mac.
- **A memory guard.** Editing runs in its own process. LocalSR checks free
  memory before it starts, and a small supervisor stops the edit if the Mac
  runs short or starts to swap, instead of letting the system grind.

## Known limitations

- Edit is **experimental**. Its memory profiles are estimates: on the 16 GB
  M1 Pro used for development, the guard stopped both test edits because other
  apps left too little memory free, so no real edit has been validated yet.
  Close other apps before editing.
- Edits are 512, 768 or 1024 px on the longest side, one image at a time.
- Qwen Image 2.1 is not offered: its license allows research and evaluation
  only.
- HDR preservation, SeedVR2 3B, de-flicker and video face processing are Labs
  features with unverified perceptual quality.
- The two HAT face companions still require a manual import.

The full list is in [KNOWN_LIMITATIONS.md](https://github.com/HerRei/local-upscale/blob/main/KNOWN_LIMITATIONS.md).
