# LocalSR v0.6.1-beta (hotfix)

A hotfix for 0.6.0: on macOS 14 and 15 the 0.6.0 engine stopped at start. Update from inside the app, or download it below. Everything new in 0.6.0 is in the [0.6.0 release notes](https://github.com/HerRei/local-upscale/releases/tag/v0.6.0-beta).

## Which file do I need?

Download one file for your computer; it is all you need. The Mac version includes everything. On Windows and Linux, LocalSR checks your graphics card when it first starts and offers the faster engine for it (NVIDIA CUDA, DirectML for AMD and Intel graphics on Windows, AMD ROCm on Linux), then downloads and installs that engine itself.

| Computer | Download |
|---|---|
| Mac (M1 or newer) | `LocalSR-v0.6.1-beta-macOS-arm64.dmg` |
| Windows | `LocalSR-v0.6.1-beta-Windows-CPU-x86_64.exe` |
| Linux | `LocalSR-v0.6.1-beta-Linux-CPU-x86_64.AppImage`, or `LocalSR-v0.6.1-beta-Linux-CPU-amd64.deb` on Ubuntu and Debian |

## Offline and advanced downloads

Only for a computer without internet access, or to install the GPU edition in one go. Everyone else can skip this.

| Computer | Download |
|---|---|
| Windows, AMD or Intel graphics | `LocalSR-v0.6.1-beta-Windows-DirectML-x86_64.exe` |
| Windows, NVIDIA | `LocalSR-v0.6.1-beta-Windows-CUDA-x86_64.exe` and all `LocalSR-v0.6.1-beta-Windows-CUDA-x86_64.engine.tar.gz.part-*` files in the same folder |
| Linux, AMD | all `LocalSR-v0.6.1-beta-Linux-ROCm-x86_64.AppImage.part-*` files, joined |
| Linux, NVIDIA | all `LocalSR-v0.6.1-beta-Linux-CUDA-x86_64.AppImage.part-*` files, joined |

To import an engine offline, download the `*.engine-payload.json` manifest, its `.engine.tar.gz.part-*` files and their `.sig` signature files into one folder, then open **Advanced -> Engine -> Change… -> Import engine from file…** and choose the `*.engine-payload.json` file.

### What are all the other files?

- `*.engine-payload.json`, `*.engine-update.json` and `*.engine.tar.gz.part-*`: the GPU engines that the app downloads by itself.
- `*.app.tar.gz` and `*.sig`: update files and their signatures, which the app checks before it installs an update.
- `*.sha256` and `SHA256SUMS`: checksums to check a download by hand.
- `*source-and-notices.tar.gz`: the source code and licence notices for each package.

## What changed

- **Hotfix: the Mac engine starts again on macOS 14 and 15.** 0.6.0 contained a part of
  MLX (the library behind FlashVSR) that only macOS 26 can load, so on older macOS the
  engine stopped right at start with "The inference engine ended unexpectedly" (#183).
  0.6.1 ships the macOS 14 build of MLX, and a release check now refuses any file that
  needs a newer macOS than LocalSR supports. If MLX ever fails to start, only FlashVSR
  is turned off; the rest of LocalSR keeps working.
- **Videos with repeated timestamps.** Some videos have frames with the same or an
  earlier timestamp than the frame before (cuts without re-encoding, screen recordings,
  some phone videos). LocalSR stopped with "Video presentation timestamps must
  increase"; it now processes them (#177).
- **Stuck on the CPU after the GPU went missing once.** When the engine started once
  without the GPU (for example while the disk was full), LocalSR saved the CPU as the
  device and kept every later run on the CPU, even after the GPU was back. It now keeps
  your device and only runs on the CPU while the GPU is missing. Work that runs on the
  CPU now always uses full precision there: half precision on the CPU took many minutes
  for a single tile. If LocalSR has run on the CPU since 0.6.0 although your computer
  has a GPU, choose the GPU again under Settings.
- **Release tooling.** The media runtime builds in a uv venv and behind mirrors whose
  certificate Python cannot check (#181), and signing takes the Windows and Linux
  packages from the draft release instead of 45 GB of CI artifacts (#180).
