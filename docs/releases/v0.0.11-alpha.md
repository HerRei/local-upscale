# LocalSR v0.0.11-alpha

This testing-only alpha advances the Tauri/Svelte desktop host, release recovery, media
automation, and reproducible performance diagnostics. Video remains **Labs / Experimental** and
`beta_ready` remains false.

## Download

Choose exactly one installer for your system:

- `LocalSR-v0.0.11-alpha-Linux-x86_64.AppImage` — Linux x86-64 CPU
- `LocalSR-v0.0.11-alpha-Windows-x86_64.exe` — Windows 10/11 x86-64 CPU
- `LocalSR-v0.0.11-alpha-macOS-arm64.dmg` — Apple Silicon macOS 12+

Verify the installer against `SHA256SUMS`. `release-index.json` records the exact source commit,
selected workflow attempt, architecture, worker smoke, model, and signing evidence.

## Important trust warning

This is an explicitly testing-only release. The macOS app is ad-hoc sealed, is not Developer ID
signed or notarized, and was only statically cross-build verified on the Intel Mac mini. The
Windows installer is not Authenticode signed. Gatekeeper or SmartScreen may warn or reject these
downloads. Production signing, notarization, timestamping, native Apple-Silicon execution, and
physical target testing remain mandatory beta gates.

The one-release macOS cross runtime also retains known PyTorch 2.2.2 and Diffusers 0.35.2 security
debt. LocalSR does not enable Diffusers remote custom pipelines, but this is not a maintained beta
runtime. On Linux, Tauri's current GTK3 stack transitively uses the advisory-affected `glib` 0.18
line; a safe fix requires the upstream GTK4 migration. These limitations are disclosed rather than
hidden or mislabeled as production-ready.

## Highlights

- Adds a reproducible, cancellable local benchmark through the production inference path with
  local JSON history and export.
- Adds synchronized original/enhanced video comparison playback with one scrubber and an
  accessible shared divider.
- Keeps enhanced live-frame previews bounded, sampled, job-scoped, and independent of progress.
- Adds explicit restoration pipelines, face fidelity blending, native 2× support, CLI processing,
  benchmark and watch-folder automation. Face masks use a pinned, on-demand MIT YuNet detector;
  the restoration checkpoint itself remains user-supplied because its rights are unresolved.
- Adds FBCNN JPEG artifact restoration before upscaling, safe EXIF/ICC handling, atomic image
  outputs, and MP4/MKV audio/subtitle remux validation with deterministic generated fixtures.
- Hardens release preflight, cross-attempt matrix selection, 48-hour failed-build evidence, and
  safe resumption of matching partial draft releases.

## Known limitations

- Only Linux CPU, Windows CPU, and Apple-Silicon macOS packages are offered by this alpha.
- The macOS package uses the one-release PyTorch 2.2.2 / Diffusers 0.35.2 Intel-to-ARM cross-build
  exception. It must not be reused for beta.
- Video codecs, stream remuxing, temporal models, live previews, and queue combinations remain
  experimental and require broader physical testing.
- Optional model weights keep their upstream licenses. The HAT-S Face checkpoint has unresolved
  independent weight/training-data rights and is accepted only as a hash-matching user-supplied
  file. Models with ambiguous terms are not presented as commercially licensed.
- The private repository does not yet provide a public feedback route.
