# LocalSR v0.1.2-beta

Phone and camera videos now open on a Mac without installing anything.

## Download

- `LocalSR-v0.1.2-beta-macOS-arm64.dmg` — Apple Silicon, macOS 14 or later
  (size and SHA-256 in `SHA256SUMS`)

Installed betas update themselves: the app checks the feed at launch, verifies
the download's size, SHA-256 and signature, backs up settings, recipes and the
queue, then installs and restarts. This update also replaces the inference
engine, so it downloads about 1 GB.

## What's new

- **H.264, HEVC and AAC through macOS.** LocalSR still ships only royalty-free
  codecs. On a Mac it now hands H.264/HEVC/AAC files to the codecs Apple ships
  with the system, through a small helper (`localsr-media`, AVFoundation). iPhone
  and camera recordings open directly, and H.264/HEVC exports — including
  10-bit HLG/PQ HEVC — are written by the system encoder into MP4. Rotation,
  variable frame rate timing, colour tags and audio survive the trip.
- **A found FFmpeg is used automatically.** If FFmpeg is installed (Homebrew,
  winget or your distribution's package), LocalSR uses it for the formats macOS
  cannot read (WMV, DivX, FLV, H.263) and for H.264/HEVC in MKV. Selecting one
  under Advanced settings is only needed to pick a different build.
- **A better FFmpeg notice.** When a file does need FFmpeg, the notice shows the
  install command for your actual system (Homebrew, winget, apt, dnf with the
  RPM Fusion note, pacman, zypper, apk) and can run it in a terminal window.

## Fixed

- Opening a file with LocalSR while the app was not running crashed at launch.

## Known limitations

- H.264/HEVC exports through the system codecs go into MP4 (or MOV); choose
  MP4, or use an installed FFmpeg for MKV.
- HDR preservation, SeedVR2 3B, de-flicker and video face processing are Labs
  features with unverified perceptual quality.
- The two HAT face companions still require a manual import.

The full list is in [KNOWN_LIMITATIONS.md](../../KNOWN_LIMITATIONS.md).
