# LocalSR v0.1.1-beta

The first public beta of LocalSR, for Apple Silicon Macs running macOS 14 or
later.

## Download

- `LocalSR-v0.1.1-beta-macOS-arm64.dmg` — 414 MB,
  SHA-256 `389336915fdc2dd254dc043ed6c8bf74eb39e8afcd3ea0de89d0ec18ab2c0505`

The app is Developer ID signed and notarized. It checks for updates at launch;
updates are downloaded in the app and verified by size, SHA-256 and signature
before they are installed, with settings, recipes and the queue backed up first.
Models are not bundled: the 4.5 MB Quick model downloads on first use, the
others when you choose them.

Windows and Linux builds come out of the same pipeline but are not published
yet. [Platforms](../platforms.md) explains why.

## What's new

- **Model library.** Choose Quick or Best, photo or illustration, and what to fix
  first; the plan card names the model for each stage with its license, size and
  hardware fit. The library sheet shows every verified model with its author,
  source, license and integrity check. Four new models: Real-ESRGAN ×4 and ×4
  Anime 6B, SwinIR-M ×4 and SCUNet.
- **Restore task** (formerly Denoise) with noise, JPEG artifact and motion blur
  removal before an upscale.
- **Old recordings.** AVI/DivX, MPEG/VOB, camcorder transport streams, WMV, FLV,
  3GP and OGV import. Tagged interlacing is deinterlaced and non-square pixels
  are normalised before enhancement.
- **Royalty-free media runtime.** LocalSR ships only patent-free codecs. Phone
  and camera videos in H.264 or HEVC open after you install FFmpeg and select it
  under Advanced settings → Video; the app shows the install command when you
  add such a file. Exports default to AV1, with VP9 and lossless FFV1 built in.
- **In-app updates** for the macOS build, with a separate engine payload so a
  small app update does not re-download the 1 GB inference engine.
- **Benchmarks** for CPU and GPU separately, drawing the model's real tiles.
- Folder jobs save together in `LocalSR Results`; queue estimates say what has
  been measured; live tiles follow the model's tile geometry exactly.

## Known limitations

- H.264/HEVC sources and exports need a user-installed FFmpeg.
- HDR preservation, SeedVR2 3B, de-flicker and video face processing are Labs
  features with unverified perceptual quality; SeedVR2 exports SDR and needs a
  lot of memory.
- NAFNet can reject some scanned documents rather than saving unstable output.
- The two HAT face companions require a manual import because their checkpoint
  rights are unresolved.
- Opening a file *with* LocalSR while the app is not running can crash it at
  launch; start the app first, then open or drop the file.

The full list is in [KNOWN_LIMITATIONS.md](../../KNOWN_LIMITATIONS.md).

## Requirements

Apple Silicon, macOS 14 or later, 16 GB of memory recommended for video.
Processing is not real time: try a short clip or a small image before a long
job, and keep your originals.
