# LocalSR v0.1.7-beta

Large upscales now appear in the comparison view after saving.

## What changed

A 12 MP phone photo enlarged 4× becomes a 195 MP image. LocalSR could save it,
but the preview decoder then refused to open it because it exceeded Pillow's
pixel limit. That left the finished result hidden behind a “too large” error.

Completed images now use a separate decoder when needed, which sends a preview
of at most 2048 pixels on the longest side to the app. Your saved image keeps
its full resolution. The app also reuses the latest preview instead of decoding
the same result twice, and refreshes it when the file changes.

The README has clearer wording, a real before-and-after example and a new
screenshot of the model library.

[v0.1.3-beta](https://github.com/HerRei/local-upscale/releases/tag/v0.1.3-beta).

## Validation

Reproduced the old failure with a 16128 × 12096 PNG (195 million pixels), then
confirmed that it opens as a 2048 × 1536 preview with the fix. Regression tests
cover PNG, JPEG, TIFF and WebP, preview reuse, file replacement and decoder
failure. The source-image decoder keeps its existing pixel checks.

## Known limitations

Editing, SeedVR2, HDR preservation, de-flicker and video face processing remain
experimental. See [KNOWN_LIMITATIONS.md](https://github.com/HerRei/local-upscale/blob/main/KNOWN_LIMITATIONS.md)
for the current list.

Report problems on [GitHub Issues](https://github.com/HerRei/local-upscale/issues)
with your app version and steps to reproduce.
