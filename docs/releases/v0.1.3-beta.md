# LocalSR v0.1.3-beta

Open now opens the file you selected, the app has a user guide, and it is
simply called LocalSR.

## Download

- `LocalSR-v0.1.3-beta-macOS-arm64.dmg` — Apple Silicon, macOS 14 or later.
  Signed and notarized; uses the Metal (MPS) backend.
- `LocalSR-v0.1.3-beta-Windows-CPU-x86_64.exe` — Windows 10 or later, 64-bit.
  CPU processing. The installer is **not** signed, so SmartScreen shows a
  warning: choose *More info → Run anyway*, after checking the SHA-256.
- `LocalSR-v0.1.3-beta-Linux-CPU-x86_64.AppImage` — glibc 2.39 or newer
  (Ubuntu 24.04 and later). CPU processing. `chmod +x` it and run it.
- `…-source-and-notices.tar.gz` — one per platform: source, build instructions
  and third-party license notices for exactly that build.

Every file's SHA-256 is in `SHA256SUMS` and in the `.sha256` beside it.

Installed macOS betas update themselves: the app checks the feed at launch,
verifies the download's size, SHA-256 and signature, backs up settings, recipes
and the queue, then installs and restarts. This update also replaces the
inference engine, so it downloads about 730 MB. The Windows and Linux builds
have no updater yet — come back to the
[download page](https://herrei.github.io/localsr/download/) for the next one.

## What's new

- **A user guide.** *Help → LocalSR User Guide* and the app menu open a short
  guide to the three tasks, models, batches, video and where results are saved:
  <https://herrei.github.io/localsr/guide/>.
- **A welcome on first launch.** It points to the guide and says plainly that
  the update check sends an anonymous count (app version, platform, channel)
  and where to turn it off. It appears once.
- **Windows and Linux.** LocalSR now has a Windows installer and a Linux
  AppImage, both built from the same licensing-clean media runtime as the Mac
  build, each with its own corresponding source.
- **The app is called LocalSR.** The installer, menu bar, About box and Finder
  Quick Action no longer say "LocalSR Next Preview". Settings, models and the
  update channel are unchanged. An installed beta keeps its current file name
  when it updates; rename it in Finder if you like.

## Fixed

- **Open and Reveal used the wrong file.** After a batch, the buttons opened
  whichever result finished last, whatever was selected. They now act on the
  selected item's result, including results from an earlier session.
- **The comparison handle drifted with the image.** When zoomed or panned, the
  ↔ handle followed the image's centre and grew or shrank with the zoom. It now
  stays in the middle of the preview frame at the same size.
- The app declared macOS 12 as its minimum, but its PyTorch libraries need
  macOS 14. Older systems now get a clear message from Finder instead of an
  engine that does not start.

## Known limitations

- GPU acceleration is Apple Silicon only. The Windows and Linux builds process
  on the CPU, which is several times slower; CUDA, ROCm and DirectML packages
  are not published (the reasons are in `docs/licensing-media.md`).
- The Windows installer is not Authenticode-signed and neither Windows nor
  Linux can update itself yet.
- H.264/HEVC exports through the system codecs go into MP4 (or MOV); choose
  MP4, or use an installed FFmpeg for MKV.
- HDR preservation, SeedVR2 3B, de-flicker and video face processing are Labs
  features with unverified perceptual quality.
- The two HAT face companions still require a manual import.

The full list is in [KNOWN_LIMITATIONS.md](https://github.com/HerRei/local-upscale/blob/main/KNOWN_LIMITATIONS.md).
