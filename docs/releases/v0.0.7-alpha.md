# LocalSR v0.0.7-alpha

This is a **private alpha evidence build**, not a public beta. It is intended for controlled testing
with trusted media and trusted model checkpoints.

## Important trust limitations

- The macOS apps are ad-hoc signed because Developer ID/notarization credentials are not configured.
  Gatekeeper may reject them. Windows executables are not Authenticode signed.
- The macOS cross-build contains PyTorch 2.2.2, the last release with matching Intel and
  Apple-Silicon wheels. It is affected by open security advisories, including
  [GHSA-53q9-r3pm-6pq6](https://github.com/advisories/GHSA-53q9-r3pm-6pq6). Do not load untrusted
  `.pth` or `.pt` files.
- Video, SeedVR2, de-flicker, and multi-video batching are Labs / Experimental.
- The face checkpoint is non-commercial (CC BY-NC-SA 4.0). Best and anime checkpoints have an
  unclear upstream `CC-BY-0.4` label and should not be assumed commercially licensed.

## What changed

- Replaced four dead image-model downloads and pinned every replacement by size and SHA-256.
- Added a real empty-cache Quick/Best download, Spandrel load, and CPU-inference release check.
- Synchronized v0.0.7-alpha metadata and made alpha tags explicit GitHub prereleases.
- Added PE/ELF/Mach-O inspection, exact architecture checks, backend provenance, and distinct archive
  digest enforcement for the complete release matrix.
- Added a production-ready macOS Developer ID signing/notarization path that fails on partial secret
  configuration and reports ad-hoc status when no production credentials exist.
- Fixed multi-video queue continuation and labeled all video/SeedVR2 surfaces experimental.
- Included SeedVR2 data and notices in wheel/source packages, added Slint attribution, refreshed the
  public documentation, and removed unsupported Homebrew/installer claims.
- Added privacy-filtered Copy Diagnostics and a documented acceptance/known-limitations checklist.

## Download and verify

Choose exactly one backend archive for your platform. Each logical archive has a `.sha256`,
`.metadata.json`, and `.architecture.txt` sidecar in the release assets or release index. Large
assets may be split into numbered parts; follow `release-index.json` to reassemble them, then verify
the published SHA-256 before opening the archive.

See `KNOWN_LIMITATIONS.md` and `docs/acceptance.md` in this tag for the remaining public-beta gates.
