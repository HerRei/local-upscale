# LocalSR v0.0.8-alpha

This is a **private alpha evidence build**, not a public beta. It moves the release process closer
to beta without choosing unresolved platform, licensing, credential, or public-feedback policy.

## What changed

- Added a CI-validated `beta-readiness.json` release asset. It records one automated gate as passed
  and leaves every credential, physical test, external clarification, product decision, and Labs
  gate explicitly unresolved.
- Added an acceptance-record template for hardware, OS/driver, artifact digest, copied diagnostics,
  real-media edge cases, resource pressure, and thermals.
- Bounded Windows scratch cleanup so large CUDA environments cannot leave the sole runner busy
  indefinitely after the verified artifacts have already transferred.
- Kept all video, SeedVR2, de-flicker, codec, and multi-video behavior labeled Labs / Experimental.

## Important trust limitations

- The macOS apps are ad-hoc signed because Developer ID/notarization credentials are not configured.
  Gatekeeper may reject them. Windows executables are not Authenticode signed.
- The macOS cross-build contains PyTorch 2.2.2 and is not a public-beta candidate. Native Apple
  Silicon/current-PyTorch work and the Intel-support decision remain open.
- The optional face checkpoint is noncommercial. The Best and anime checkpoints still need upstream
  clarification of their nonstandard `CC-BY-0.4` label.
- The repository and feedback route are not accessible to general beta users.

## Download and verify

Choose one backend archive for your platform. Verify it using its `.sha256`, `.metadata.json`, and
`.architecture.txt` sidecars (or the split-asset instructions in `release-index.json`). Review
`beta-readiness.json` before testing: `beta_ready` is intentionally `false` for this alpha.
